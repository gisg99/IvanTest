🧪 Reto Técnico – Becario de Desarrollo Web

Bienvenido Ivan 👋  
Este repositorio contiene los recursos necesarios para realizar el reto técnico como parte del proceso de selección.

---

🎯 Objetivo

Desarrollar el diseño de un portal web a partir de una imagen de referencia y los assets proporcionados.

Puedes utilizar el lenguaje y tecnologías con las que te sientas más cómodo/a (React, HTML/CSS/JS, Node.js, PHP, Python, etc.).

---

📦 Cómo empezar

Sigue estos pasos para trabajar en el proyecto:

1. Clona el repositorio
git clone [URL_DEL_REPOSITORIO]

2. Accede al directorio del proyecto
cd [NOMBRE_DEL_REPOSITORIO]

3. Crea una nueva rama con tu nombre
git checkout -b reto-[tu-nombre]

4. Desarrolla tu solución

5. Sube tus cambios
git add .
git commit -m "Entrega reto técnico"
git push origin reto-[tu-nombre]

---

📁 Estructura del repositorio

- /assets → Recursos gráficos (imágenes, logos, etc.)  
- /src → Carpeta sugerida para tu desarrollo (puedes modificarla si lo necesitas)

---

✅ Requerimientos

Tu solución debe cumplir con lo siguiente:

- Replicar lo más fielmente posible el diseño proporcionado
- Código limpio, ordenado y bien estructurado
- Uso de buenas prácticas de desarrollo
- Diseño responsive (adaptable a diferentes dispositivos)
- Uso de Git (commits claros y organizados)

---

⭐ Extras (Opcional, suma puntos)

- Deploy del proyecto (Vercel, Netlify, etc.)
